# 🌍 Darukaa.Earth — AI Biodiversity Intelligence

> An AI-powered biodiversity intelligence system that combines environmental reasoning, scientific literature retrieval, structured environmental data, GBIF biodiversity observations, and Gemini-powered conversational analysis to generate evidence-backed ecosystem recommendations.

---

## 📌 Overview

**Darukaa.Earth** is an AI-based biodiversity intelligence chatbot designed to analyze environmental conditions and provide scientifically grounded recommendations for improving ecosystem health.

Unlike a generic LLM chatbot, Darukaa.Earth combines multiple layers of environmental intelligence:

- 🌱 Environmental rule-based reasoning
- 📚 Scientific literature retrieval using RAG
- 🗂️ Structured environmental knowledge
- 🧬 Biodiversity observations from GBIF
- 🤖 Gemini-powered response generation
- 💬 Conversational memory
- 🔗 Multi-metric environmental reasoning
- 📍 Optional geographic biodiversity analysis
- 📊 Structured JSON environmental input

The system connects environmental variables such as:

```text
Soil Health
     ↓
Climate Conditions
     ↓
Land Use
     ↓
Habitat Conditions
     ↓
Human Impact
     ↓
Biodiversity
```
